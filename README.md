##  Repository Layout

To keep game files isolated from production and design assets, our repository has a following directory structure:

```text
/
├── README.md               <-- You are here (Repository front page)
├── .gitignore              <-- Root gitignore configuration
├── docs/                   <-- Game Design Document
│       └── README.md       <-- Documentation hub & rules
└── game/                   <-- GODOT PROJECT ROOT (project.godot lives here)
        ├── assets/         <-- Exported textures, sounds, and fonts
        ├── scenes/         <-- Godot scene files (.tscn)
        └── scripts/        <-- GDScript files (.gd)
